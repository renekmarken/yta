SCRT Uploader

A private publishing tool for the YouTube channel “Secret” (@SCRT)

SCRT Uploader is an internal tool used only by the owner of the YouTube channel “Secret” (@SCRT). It produces review videos about websites and apps and uploads them to that one channel through the YouTube Data API, together with their title, description, tags, thumbnail and captions.

Who uses it

Only the channel owner. There is no public sign-up, and no other person signs in to or uses this application.

What it accesses

  • Permission to upload videos to the owner's own channel (youtube.upload).
  • Permission to set thumbnails and captions on those videos (youtube).

Uploaded videos are set to unlisted so the owner can review them in YouTube Studio before publishing.

YouTube API Services

SCRT Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy.
