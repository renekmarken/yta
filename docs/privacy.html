Privacy Policy

Last updated: October 2, 2026

This policy explains how YT Uploader (“the app”) handles information. The app is a personal tool operated by and for the owner of the YouTube channel “Secret” (@SCRT). It has no other users.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information the app accesses

  • An OAuth authorization (refresh token) for the channel owner's Google account, limited to the youtube.upload and youtube scopes.
  • The ID of each video it uploads, so it can attach the thumbnail and captions and record the link.

The app does not read, collect or store any other YouTube data, such as viewer information, comments, analytics or other channels' content.

How the information is used

Only to upload the owner's own videos to the owner's own channel and to set their thumbnail and captions.

Storage and security

The authorization is stored as an encrypted secret in the owner's GitHub repository and is used only by the owner's automated workflow. It is never published, sold or shared with anyone.

Sharing

No information is shared with third parties, except that video files and their details are sent to YouTube as part of uploading them.

Cookies

The app has no user interface and sets no cookies. This website sets no cookies and uses no tracking.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions or through Google's security settings page. Revoking access makes the stored authorization useless, and it is then deleted from the repository. Uploaded videos can be deleted in YouTube Studio.

Changes

If this policy changes, the updated version will be posted on this page with a new date.

YT Uploader is a personal tool and is not affiliated with or endorsed by YouTube or Google.
